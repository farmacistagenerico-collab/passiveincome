# PassiveZero — Aggregatore & Formulatore di Entrate Passive a Costo Zero

Piattaforma gratuita che **aggrega** 24 fonti di reddito passivo (tutte a costo zero) e le **formula** in un piano personalizzato.

## Funzionalità

- **Aggregatore** — 24 fonti passive verificate con filtri (categoria, difficoltà), ricerca, ordinamento e guida step-by-step per ciascuna
- **Formulatore** — wizard in 5 domande (tempo, skill, obiettivo, stile, velocità) che genera un portafoglio personalizzato di 4 fonti con allocazione del tempo e stime a 3/6/12 mesi
- **Simulatore** — cursori interattivi per stimare le entrate di una fonte con grafico di crescita
- **Tracker** — registrazione entrate reali con grafico 12 mesi, totali e export CSV (dati in localStorage)
- **Roadmap 90 giorni** — piano d'azione che si adatta alle fonti selezionate dal formulatore

## Avvio

Nessuna build, nessuna dipendenza da installare. Basta un server statico:

```bash
python3 -m http.server 8000
# poi apri http://localhost:8000
```

Oppure apri direttamente `index.html` nel browser.

## Stack

HTML + Tailwind CSS (CDN) + Chart.js (CDN) + JavaScript vanilla. Zero costi di hosting e di API.
